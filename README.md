# 💻 codingtest-study

매일 1문제 이상 알고리즘 문제를 풀고 풀이 과정을 기록하는 스터디입니다.

<br>

## 📌 규칙 (Rules)
1. **1일 1문제 이상** 필수 풀이
2. 각자 이름(또는 닉네임)으로 된 폴더 내에 문제별 폴더를 생성하여 제출
3. 풀이 완료 후 메인 브랜치로 Pull Request 보내기

<br>

## 📁 폴더 구조 (Directory Structure)

```text
├── 닉네임
│   ├── [Lv.0] 문제 이름
│      ├── answer.java (언어는 자유롭게 선택)
│      └── solutionProcess.md (풀이/배운 거 기록, 없으면 작성 안 해도 됨)
