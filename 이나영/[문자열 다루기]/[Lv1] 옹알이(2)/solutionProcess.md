# [Lv.1] 옹알이(2)

### 🔗 문제 링크
- [문제 출처 링크](https://school.programmers.co.kr/learn/courses/30/lessons/133499)

### 💡 문제 접근 방식
- 발음 가능한 4가지 단어를 리스트로 두고, 각 babbling 문자열 앞에서부터 이 단어들로 계속 매칭이 되는지 확인하는 방식으로 접근. 
- 단순히 같은 단어가 연속으로 두 번 나오면 안 되는 조건이 있어서, 직전에 매칭된 단어(last_word)를 기억해뒀다가 비교

### 🛠 풀이 과정
1. remain 변수에 현재 검사 중인 문자열을 담고, 소진될 때까지 반복문 실행
2. 매 반복마다 canspeak 리스트를 순회하면서 remain이 특정 단어로 시작하는지 확인
3. 매칭되는 단어를 찾으면 found에 저장하고, 못 찾거나 직전 단어와 같으면 False 처리 후 break
4. 매칭에 성공하면 remain에서 해당 단어 길이만큼 잘라내고 last_word를 갱신
5. remain이 다 소진되고 끝까지 flag가 True로 유지되면 발음 가능한 문자열로 판단해 answer += 1
